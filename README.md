# Página de Antares

Sitio oficial de Antares para Windows y Android: https://hanyer001.github.io/Pagina-Antares/

- Windows estable: 0.3.3, 25,7 MB; conserva el actualizador integrado.
- Android: 0.3.3 Beta 1, Android 7.0+, ARM 32/64 bits. [Descarga](https://github.com/Hanyer001/antares-actualizaciones/releases/download/android-v0.3.3-beta.1/Antares-Android.apk) · [Notas](https://github.com/Hanyer001/antares-actualizaciones/releases/tag/android-v0.3.3-beta.1).
- Código: [Antares](https://github.com/Hanyer001/Antares).

`index.html` y `landing-antares/index.html` son la misma página. GitHub Pages sirve la raíz de `main`. Los enlaces de Windows siguen la última release estable; Android apunta a su etiqueta específica para no alterar el canal de Windows. En Android el botón principal descarga el APK; en Windows descarga el instalador.

La edición Android Beta no se anuncia como estable. Preview puede coexistir; la migración utiliza exportación y restauración de copia completa. No se anuncia un actualizador Android dentro de la app: aún no está implementado.

Los paquetes se alojan como assets de GitHub Releases. No subir firmas privadas, contraseñas, credenciales ni herramientas locales.
